# Бессмысленная игра

Минималистичный абсурдный кликер для Android. Нажимай на кнопку, копи единицы бессмысленности и получай сомнительные комментарии.

## Стек
Kotlin, Jetpack Compose, Material 3. Минимальная версия Android: 7.0 (API 24).

## Сборка
Открой проект в Android Studio и запусти конфигурацию `app`, либо выполни:
```bash
./gradlew assembleDebug
```
